# Tez kayıt

Lisansüstü tez kayıtlarını tutan masaüstü uygulaması.

## Ne var

Ekranlar `GraduateThesisSystem` projesindedir.

## Çalıştırma

Çözümü Visual Studio ile açıp başlangıç projesini çalıştırın. Veritabanı kullanan projelerde bağlantı dizesini kendi ortamınıza göre güncelleyin.

## Yığın

.NET Framework, Windows Forms ve Entity Framework.
